# Assets Directory

This directory contains image assets for the Amazing Secomm Coffee Cup SPA.

## Required Images

Please add the following images to this directory:

1. **cup.png** - Main coffee cup illustration
   - Recommended size: 800x800px
   - Format: PNG with transparency
   - Used in: Hero section

2. **nfc.png** - NFC icon/illustration
   - Recommended size: 200x200px
   - Format: PNG with transparency
   - Used in: Concept section (NFC One-Tap Brew feature)

3. **mood.png** - Mood icon/illustration
   - Recommended size: 200x200px
   - Format: PNG with transparency
   - Used in: Concept section (Mood-Blend System feature)

4. **qr.png** - QR code image
   - Recommended size: 400x400px
   - Format: PNG
   - Used in: Final CTA section

## Fallback Behavior

The application includes fallback placeholders if images are missing. The app will still function correctly without these images, but for the best visual experience, please add them.

## Image Sources

You can use:
- Stock photo websites (Unsplash, Pexels)
- Icon libraries (Heroicons, Feather Icons)
- Design tools (Figma, Canva)
- Custom illustrations

Make sure all images are optimized for web use to ensure fast loading times.
